### 📌 Ключевые проекты

#### 🗺️ [Minimap & Match Engine](https://github.com/covalscy/minimapMod)
- **Стек:** Java, C++, OpenGL, Многопоточность, State Machine, Сетевые пакеты
- Движок, разработанный специально для сервера **Cowax MC**. Интерактивный рендеринг карт с матрицами проекции OpenGL, фоновым неблокирующим кэшированием и автоматом состояний матча (FSM).

#### 🩸 [BleedOut](https://github.com/covalscy/BleedOut)
- **Стек:** Java, Client-Server Networking, Event-Driven Architecture
- Высоконагруженный автомат состояний жизненного цикла сущностей с собственным протоколом синхронизации пакетов, физикой ползания и межмодовым API.

#### ⚡ [[TaCZ] Optimization](https://github.com/covalscy/TaczOptimization)
- **Стек:** Java, SpongePowered Mixin, TACZ API, Профилирование рендеринга
- Мод низкоуровневой оптимизации для TACZ. Отключает избыточный 3D-рендеринг обвесов у сторонних игроков, оптимизирует отрисовку трассеров/пуль при стрельбе и снижает нагрузку на графический поток во время массовых боев.
